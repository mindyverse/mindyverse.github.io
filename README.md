### RFP Compliance & Response Readiness Case Study

Independent business analysis portfolio project based on Troy University RFP #26-004 for CRM Software.

The project involved reviewing the base RFP and official addenda, organising 45 requirements into a compliance matrix, and creating a submission checklist, risk and clarification log, response plan, opportunity brief and executive summary.

Case study:

https://mindyverse.github.io/troy-rfp.html

GitHub project repository:

https://github.com/mindyverse/RFP_Response_Readiness_Analysis
