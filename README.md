# Mindy's Portfolio Website

This is the personal portfolio site for Sanduprabha Rashmindi (Mindy).

## Structure

- `index.html` – portfolio homepage
- `assets/style.css` – shared site styling
- `projects/uk-rail.html` – UK Rail Power BI case study

## Publish with GitHub Pages

Create a public GitHub repository called `mindyverse.github.io`, upload the contents of this folder to the repository root, and GitHub Pages will serve the site at:

`https://mindyverse.github.io`

The hero illustration is currently loaded from the existing public GitHub project so the original hero image is preserved. The UK Rail dashboard screenshot is loaded from the completed UK Rail project repository.
