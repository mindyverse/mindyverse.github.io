QUICK PUBLISH — GITHUB PAGES

1. Create a new PUBLIC GitHub repository named exactly:
   mindyverse.github.io

2. Upload the CONTENTS of this folder to the root of that repository:
   - index.html
   - assets/
   - images/
   - projects/
   - README.md

3. Commit the files.

4. Open:
   https://mindyverse.github.io

GitHub Pages normally publishes a user site from a repository named <username>.github.io.

IMPORTANT ABOUT THE HERO IMAGE
The site intentionally keeps your existing hero illustration. At the moment it is loaded from your existing public GitHub project using its raw image URL. This keeps the same hero image without requiring a new copy. Later, you can copy Hero Image2.png into this portfolio repository and change the img src to a local path if you want the portfolio to be completely self-contained.
